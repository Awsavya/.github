## 🚀 Featured Engineering Projects

### 📱 [TripSplit](https://www.awsavya.in/work)
*Offline-First Android Expense Sharing & Optimal Debt Settlement*
- **Stack:** Kotlin, Jetpack Compose, Room SQLite, Firestore Sync, Graph Algorithms
- **Highlights:** Dynamic Android App Links for instant zero-signup claiming, local SQLite caching for 100% offline balance calculation, and a graph-theoretic debt minimization algorithm reducing $N$-way settlements into minimal transactions.

### 🤖 [Build2Buzz](https://www.awsavya.in/work)
*Applied AI Publishing Engine with Headless Fact Verification*
- **Stack:** Python, Playwright, LLM Orchestration, LinkedIn REST API
- **Highlights:** Autonomous product demo analysis pipeline that runs headless browser scenarios, extracts ground-truth UI state to eliminate hallucinations, and formats technical launch releases.

### 🏭 [Har Apparels](https://www.awsavya.in/work)
*Industrial Shop-Floor ERP & Roll Inventory Engine*
- **Stack:** Android, Kotlin, Barcode Scanning, Local SQLite Cache, Cloud Sync
- **Highlights:** Built for denim manufacturing plants to track raw denim rolls from dyeing and cutting through sewing and packing, preventing fabric waste with offline bundle advancement.

### 🛒 [QuicklyCart](https://www.awsavya.in/work)
*Multi-Vendor Hyperlocal Delivery Architecture*
- **Stack:** Django REST Framework, Celery, Redis, PostgreSQL, PostGIS
- **Highlights:** 4-role state machine (Customer, Store Manager, Delivery Partner, Admin) with geographic order dispatch, live status transitions, and automated inventory reconciliation.
